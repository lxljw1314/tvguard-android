# TVGuard Android 在线安装包

当前版本 v1.29.1（versionCode 35），适用于可安装 APK 的 Android/Google TV、Android 手机和平板。

- 在线安装页：打开本目录的 `index.html`
- APK：`TVGuard-v1.29.1.apk`
- SHA256：`a1cb63f2828408d067f24534359936c8e996e1ec81af7c50052723478c27082c`
- 下载、安装和同 Wi-Fi 升级无需 Windows 或命令行。首次授权另受电视系统限制，不代表安装后自动取得权限。
- 首次电视安装仍需电视系统确认一次；后续同一 Wi-Fi 下可由手机控制页发起升级

本版本统一了电视、电视盒子、手机和平板的设备角色判定，避免部分同时声明触摸屏和 Leanback 的电视盒子被误判为手机。


## v1.32.0 测试版：独立题库管理

不同家庭需要各自的教材和题库。v1.32 新增独立题库管理：默认整套替换，也可按科替换或追加去重；每科和整套题库均能启用、停用、删除，并可撤销上一次题库变更。

- 手机主页 → 本机题库管理；手机遥控连接电视后 → 电视题库管理；浏览器控制页也支持管理。页面标明目标设备，全部写操作需家长密码，先预览再确认。
- 新安装提供默认停用的 12 道通用体验题，可直接删除或替换。旧版覆盖升级保留原题库、观看规则、积分和统计。
- 支持单科和自定义科目，不再要求四科齐全或每科至少三道。整套替换会移除新包未包含的旧科目；追加要求教材一致并去重。
- 没有启用题目时继续计时统计，暂停答题和依赖答题页的每日时长拦截；删空后重开仍为空。正在答题的一轮使用旧题目，变更从下一轮生效。
- 电视没有文件选择器时提示从手机导入。手机本机题库通过本机接口管理，无需连接 Wi-Fi；管理电视仍需同一 Wi-Fi。

验证：17 项单元测试通过、1 项可选真实 adbd 测试跳过；题库管理完整仪器流程及旧题库/统计/100轮科目配额回归通过。最终签名 release 覆盖安装保留隔离模拟器的 273 道原题及停用选择，今日用时保持 1341 秒，空题库实际用时增至 1344 秒；撤销恢复及可见答题预览通过。HTTP 的错误密码、损坏文件、大小限制和 4000 题上限均验证。

本版为测试版，正式版仍保留 v1.29.1；雷鸟、Redmi 等真机仍待验收。延续 v1.31.1 的手机首次设置流程，仍需可用系统授权入口或可开启的传统网络调试，暂不支持 TLS 配对码。系统“强行停止”会在此模拟器移除无障碍登记，本次通过已有家长恢复接口恢复后验证计时，不将其算作自动恢复成功。

装机统计尚未接入。APK 下载次数不能代替安装量；匿名激活统计需要后续增加接收服务和设备端上报。

安装：手机与电视均覆盖安装 v1.32，使用同一个 APK。电视可继续从同 Wi-Fi 的手机遥控页上传 APK，在电视确认安装；不要先卸载旧版。

## v1.31.1 测试版：手机协助首次设置与实际验证

电视缺少无障碍入口、家长没有电脑时，手机内置首次设置流程会检查现有权限，并在电视允许传统网络调试时完成一次授权；只有观察到实际用时增加和电视答题页可见，才显示验证完成。

- 已授权电视跳过调试；已有自动恢复授权的电视可以直接恢复服务。缺少首次权限时，按本机指引开启调试或打开真实系统授权页。
- 测试答题及关闭测试页保留本轮时长和学习统计，不能用测试关闭按钮关闭正式答题；设置操作受家长密码保护。
- 同一 APK 用于安卓手机、电视和平板。只控制电视的手机无需开启本机计时权限或开发者模式；手机、电视建议均覆盖安装本版。

验证：17 项单元测试通过、1 项可选真实 adbd 单测跳过；Android TV 模拟器完整首次授权、恢复、计时及答题流程通过。最终 release 覆盖安装保留今日 424 秒，用时随后增长至 427 秒，答题预览与关闭也通过，签名与旧版一致。

限制：仍需系统无障碍入口或可开启的传统网络 ADB 至少一条通路，电视要求确认时由家长确认。尚不支持无线调试配对码／TLS；同时封闭授权入口与调试的固件无法由普通 APK 自行授权。当前没有已选定验收的预配置盒子型号。雷鸟与 Redmi 等真机首次安装仍待验收，因此本版为测试版，正式下载仍保留 v1.29.1。

安装后：手机遥控 → 选择电视并验证家长密码 → 电视首次授权（无需电脑） → 验证计时 → 测试答题弹出。覆盖安装保留配置、题库与每日统计；勿卸载旧版。
