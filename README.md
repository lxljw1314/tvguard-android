# TVGuard Android 在线安装包

当前版本 v1.29.1（versionCode 35），适用于可安装 APK 的 Android/Google TV、Android 手机和平板。

- 在线安装页：打开本目录的 `index.html`
- APK：`TVGuard-v1.29.1.apk`
- SHA256：`a1cb63f2828408d067f24534359936c8e996e1ec81af7c50052723478c27082c`
- 下载、安装和同 Wi-Fi 升级无需 Windows 或命令行。首次授权另受电视系统限制，不代表安装后自动取得权限。
- 首次电视安装仍需电视系统确认一次；后续同一 Wi-Fi 下可由手机控制页发起升级

本版本统一了电视、电视盒子、手机和平板的设备角色判定，避免部分同时声明触摸屏和 Leanback 的电视盒子被误判为手机。


## v1.30.0 测试版：手机协助首次授权

手机安装 `TVGuard-v1.30.0.apk`，在“手机遥控”验证电视家长密码后，选择“电视首次授权（无需电脑）”。电视须开启传统 ADB／网络调试并确认连接；手机 App 内置完成授权和状态复核，无需第三方助手或输入命令。仅控制电视的手机可直接跳过本机计时权限。

本轮已验证 Android TV 模拟器的真实 RSA 认证、权限授予、服务连接与用时增长；尚未完成各品牌真机首次授权验证。暂不支持无线调试 TLS 配对码；同时封闭设置入口和网络调试的固件暂不支持。v1.29.1 仍为正式下载版本，v1.30.0 标为测试版。
