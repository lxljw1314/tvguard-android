# TVGuard Android 安装入口

这是 TVGuard 的 Android 发布页，适用于可安装 APK 的 Android/Google TV、Android 手机和平板。

- 在线安装页：[打开安装页](https://lxljw1314.github.io/tvguard-android/)
- 当前版本：v1.29.0（versionCode 34）
- APK：[下载 TVGuard-v1.29.0.apk](./TVGuard-v1.29.0.apk)
- SHA256：`384a2fd76931c89859ba6efc7545f3d62427b7e36398fd8f8091aced64caed5e`

普通家长不需要 Windows、ADB 或命令行。首次安装仍需按 Android 系统提示允许安装未知应用并确认安装；电视后续升级可由同一 Wi-Fi 下的手机控制页发起。
